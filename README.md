## How to deploy AizaWorld token contracts
1. Install dependencies
    ```
    npm i
    ```
1. Copy the example env to yours:
    ```
    cp .env.example .env
    ```
1. Build contracts:
    ```
    npm run build
    ```
1. Deploy contracts:
    ```
    npm run deploy
    ```
